Get started in 3 steps
1

Download & Extract

Download the ZIP above. Go to downloads folder and Right-click it → Extract All to turn it into a normal folder.

2

Open Extensions

Go to chrome://extensions or Chrome menu → Extensions, then top right turn on Developer mode.

3

Install LogIn

On top left click Load unpacked, then select the extracted LogIn folder to install the chrome extension.

Done — LogIn will now appear in your Chrome extensions.
