05 / GOOD TO KNOW

A few things
worth knowing.

Designed to simplify access, not to bypass website rules or replace your organization's security policies.

Do team members need the website password?+

LogIn is designed to let authorized users work with an administrator-provided website session without requiring them to enter the underlying website password. Session access is still sensitive and must be managed responsibly.

Can an administrator remove access?+

Yes. Administrators have controls to suspend users, manage account assignments, and reset registered devices. Ending LogIn access does not necessarily revoke a third-party website session outside LogIn.

Does LogIn work on every website?+

LogIn is designed for administrator-configured websites. Compatibility varies with each website's authentication system, security restrictions, and terms of service.

Why does the extension use cookies and proxy settings?+

Cookies help apply a managed login session. Proxy support lets administrators set the network configuration needed by a particular assigned website. See our Privacy Policy for details.
