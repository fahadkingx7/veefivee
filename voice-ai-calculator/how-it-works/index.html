Imagine someone calls your business. This is what happens behind the scenes:

1

4

That's it. Retell manages the phone and voice. DeepInfra supplies the intelligence. Cloudflare is the tiny bridge between them.

5 steps to build it

Start simple. Don't worry about advanced features until the first test call works.

1

Set up an agent in Retell

Choose a voice, name and speaking style. If you already have agents, keep them. Retell remains the place where you manage your agents and voices.

2

Get a DeepInfra API key

Create a DeepInfra account, choose the Qwen3.5 9B model (confirm its exact API model ID and availability), and generate an API key. This is what lets Cloudflare ask the model for answers.

3

Create a Cloudflare Worker

Create a small Worker called something like voice-llm-bridge. Add the DeepInfra key as a secret, not in public website code. The Worker accepts Retell's live WebSocket connection and calls DeepInfra.

4

Connect Retell to Cloudflare

Set the agent to use Retell's Custom LLM integration and enter your Worker's secure wss:// URL. The developer must follow Retell's exact WebSocket message format for requests and replies.

5

Make a test call

Call the agent. Say hello, ask a question, interrupt once, and check that it answers naturally. Then test longer calls and errors before using it with customers.

What about your existing Retell personalities?

You can keep Retell as your main dashboard. The voices stay there. For personality instructions, our preferred approach is to have Cloudflare retrieve each agent's prompt from Retell's API and pass it to DeepInfra.

Easy first version

Copy each agent's prompt once into the Worker configuration. Fastest way to get the first call working, but changes in Retell won't automatically update it.

Recommended next upgrade

Connect the Retell API so Cloudflare can look up the correct agent prompt. Cache it briefly, refresh it when needed, and send it to DeepInfra. This needs development and testing; it is not automatic out of the box.

Example: Sarah can keep her friendly female Retell voice and sales personality. James can keep his professional male voice and support personality. Both use the same DeepInfra model, but each receives different instructions.

Heads-up: Retell's advanced tools, knowledge bases and conversation flows may need extra integration with a Custom LLM. Don't assume every Retell feature transfers automatically.

Quick answers

Do we need to buy a server or GPU?

No. Cloudflare runs the connector and DeepInfra hosts the AI model. Verify Worker limits before production.

Can we keep multiple Retell agents and voices?

Yes. Each agent can have a different voice and personality. The Worker must map the correct prompt to each agent.

Can we edit prompts in Retell as usual?

That's our goal. Automatic syncing requires the developer to retrieve the appropriate Retell agent/LLM configuration through its API, then supply the prompt to DeepInfra. Start with a copied prompt to prove the connection works.

Is the integration already running?

No. This page describes what to build. The live calculator is only a cost estimator.
