GET STARTED

Up and running in 3 steps.

01

Download & extract

Click the download button above. Right-click the ZIP file and choose Extract All.

02

Open Chrome Extensions

Type chrome://extensions in Chrome's address bar, or go to ⋮ → Extensions → Manage Extensions.

03

Install LogIn

Enable Developer mode, select Load unpacked, then choose the extracted extension folder.

✧

You're all set. Open LogIn from your Chrome toolbar and follow the sign-in instructions from your administrator.
