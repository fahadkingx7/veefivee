GET STARTED

Just 3 steps to install.

Windows · macOS · Linux
01

Download & extract

Download the ZIP above. Extract all files and open the login-admin-main folder. Make sure it contains manifest.json.

02

Enable Developer mode

Open a new Chrome tab and type chrome://extensions in the address bar. Turn on Developer mode using the top-right switch.

03

Load unpacked & sign in

Click Load unpacked, select the extracted folder that contains manifest.json, then pin LogIn Admin from the Extensions menu and sign in.

✦

Important: Keep the extracted folder in place after installation. Chrome loads the extension directly from it. Only install packages you trust. This method requires desktop Chrome and does not work on Chrome for iPhone or Android.
