Large CSV files are streamed in small chunks, with support for multiple numbers, emails, companies, job titles, and notes.

How does it work?

Start with a spreadsheet where each row is a person and the first row contains column names such as Name, Phone, Email, Company. Upload the file, confirm the column mapping, then download your VCF file. If you're importing into Google Contacts or a phone, use its Import Contacts feature to select the VCF. Large CSV files are processed in chunks; large Excel workbooks may still be limited by available device memory.
